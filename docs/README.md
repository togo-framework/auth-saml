# auth-saml — docs

SAML 2.0 SSO (service-provider) login for the togo auth family.

- **Install:** `togo install togo-framework/auth-saml`
- **Marketplace:** https://to-go.dev/plugins/auth-saml
- **Source:** https://github.com/togo-framework/auth-saml

See [usage.md](usage.md) for the SP setup, IdP registration, and the endpoints.
